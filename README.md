# Cartofilia dos Afetos

Landing page da exposição curatorial **“Cartofilia dos Afetos: Histórias de Si, e do Recife em Cartões-Postais”** — Curso de História, UNICAP.

Site estático (HTML, CSS e JS puros), pronto para a Vercel. Não precisa de build.

## Estrutura
- `index.html` — conteúdo da página
- `styles.css` — identidade visual (papel #F4F1E8, marrom #7D4612; fontes Gelasio, Allura e Lato)
- `script.js` — animações de entrada e botão de som dos vídeos
- `assets/` — vídeos, fotos, selo e logos
- `fonts/` — fontes hospedadas no próprio site

## Trocar um vídeo ou imagem
Substitua o arquivo em `assets/` mantendo o mesmo nome e faça commit — a Vercel publica sozinha.
